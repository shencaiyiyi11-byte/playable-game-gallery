# PLAY / 游戏试玩库

三款游戏、六个浏览器试玩入口。首页只展示封面；选择游戏并点击“加载游戏”后才下载对应资源。

- 五境疾驰：落日海岸 finish-v1、极夜工业港 harbor-v4、万圣夜竞速 e3-full-v1。
- BREACH · 断线行动：默认启动器的射击战役灰盒。
- NO SIGNAL · 失联航次：ship-greybox-v4 原版灰盒、S01 万圣节手绘哥特版。

使用电脑键盘与鼠标。各游戏的试玩页提供操作说明。第一人称游戏点击画面锁定鼠标，Esc 释放鼠标。

使用 Godot 4.7.2 Compatibility / Web 单线程导出。原生版本中的赛车动态引擎音效在 Web 发行副本中显式使用流播放。

S01 发行副本使用 Godot 已导入的 PackedScene 加载模型；场景中的位置、尺寸适配、材质处理和玩法保持原逻辑。浏览器核验确认 12 个环境模型原件、220 个装配位置及巡逻者模型加载成功。

此仓库仅保存网页发行产物。大文件以分片形式存储，由 GitHub Actions 组装并校验 SHA-256 后部署到 GitHub Pages。浏览器访问站点时加载的是组装后的完整文件。

引擎与字体的第三方许可位于站点的 `licenses/` 目录。本仓库不为游戏素材额外授予开源许可。
