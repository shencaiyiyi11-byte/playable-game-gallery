# 五境疾驰 · 在线竞速

浏览器试玩发布包，包含两个现有风格：

- 落日海岸：finish-v1
- 极夜工业港：harbor-v4

使用电脑键盘：Enter 开赛，WASD / 方向键驾驶，空格漂移，Shift 氮气，E 道具，R 回检查点，Esc 暂停，M 声音。

使用 Godot 4.7.2 Compatibility / Web 单线程导出。原生版本中的动态引擎音效在 Web 发行副本中显式使用流播放。

此仓库仅保存网页发行产物。大文件以分片形式存储，由 GitHub Actions 组装并校验 SHA-256 后部署到 GitHub Pages。浏览器访问站点时加载的是组装后的完整文件。

引擎与字体的第三方许可位于站点的 `licenses/` 目录。本仓库不为游戏素材额外授予开源许可。
